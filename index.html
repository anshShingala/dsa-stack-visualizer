Stack using Array

Concept Library: Stack via Array

What is a Stack?

A Stack is a linear data structure that follows the LIFO (Last In, First Out) principle. The element inserted last is the first one to be removed. Think of a stack of plates: you place new plates on top, and you take plates off the top.

Array Representation

When implementing a stack with an Array, we allocate a fixed-size buffer. We track the index of the top element using a pointer variable named top. When empty, top is set to -1. The index increases as elements are added.

Edge Conditions

Because arrays have fixed capacity, we must check for:

  • Stack Overflow: Adding to a full stack (top == SIZE - 1).
  • Stack Underflow: Removing from an empty stack (top == -1).

Concept Library: Infix to Postfix

Conversion Logic

An Infix expression (e.g., A+B) has operators between operands. A Postfix expression (e.g., AB+) places operators after operands, eliminating the need for parentheses and operator precedence rules during evaluation.

Stack Role

We use an operator stack to temporarily store operators and parentheses. When an operator is scanned, we pop and output operators of higher or equal precedence from the stack before pushing the new operator.

Operator Precedence

Precedence rules guide which operator evaluates first: ^ (exponentiation, highest, right-associative), followed by * and / (medium, left-associative), and + and - (lowest, left-associative).

C++ Source Code

Below is the complete C++ implementation using standard templates. This code mimics the exact algorithm simulated above.

#include <iostream>
#include <stack>
#include <string>
using namespace std;

int precedence(char op) {
    if (op == '^') return 3;
    if (op == '*' || op == '/') return 2;
    if (op == '+' || op == '-') return 1;
    return 0;
}

bool isOperand(char c) {
    return isalnum(c);
}

string infixToPostfix(string expr) {
    stack<char> st;
    string result = "";

    for (char c : expr) {
        if (isOperand(c)) {
            result += c;
        } else if (c == '(') {
            st.push(c);
        } else if (c == ')') {
            while (!st.empty() && st.top() != '(') {
                result += st.top();
                st.pop();
            }
            if (!st.empty()) st.pop();
        } else {
            while (!st.empty() &&
                   precedence(st.top()) >= precedence(c)) {
                result += st.top();
                st.pop();
            }
            st.push(c);
        }
    }

    while (!st.empty()) {
        result += st.top();
        st.pop();
    }

    return result;
}

int main() {
    string expr;
    cout << "Enter infix expression: ";
    cin >> expr;

    cout << "Postfix: "
         << infixToPostfix(expr)
         << endl;

    return 0;
}
