Stack using Array

Concept Library: Stack via Array

What is a Stack?

A Stack is a linear data structure that follows the LIFO (Last In, First Out) principle. The element inserted last is the first one to be removed. Think of a stack of plates: you place new plates on top, and you take plates off the top.

Array Representation

When implementing a stack with an Array, we allocate a fixed-size buffer. We track the index of the top element using a pointer variable named top. When empty, top is set to -1. The index increases as elements are added.

Edge Conditions

Because arrays have fixed capacity, we must check for:

  • Stack Overflow: Adding to a full stack (top == SIZE - 1).
  • Stack Underflow: Removing from an empty stack (top == -1).
